# 太阳系 · 3D Solar System

纯静态的 3D 太阳系：太阳与八大行星同处一片星空，点击任意天体即可飞过去看特写。

![planets](https://img.shields.io/badge/planets-8%20%2B%20Sun-f59e0b) ![mobile](https://img.shields.io/badge/mobile-ready-3b82f6)

## 功能

- **9 个可聚焦天体**：太阳、水星、金星、地球、火星、木星、土星、天王星、海王星。点星球本体、点底部名称、或按数字键 `1`–`9` 都能切换；`0` 或「全景」回到整体视角。
- **自动朝向受光面**：聚焦行星时相机自动绕到被太阳照亮的一侧并持续跟随公转，不会一聚焦就看到全黑的夜面；拖动后即解除跟随，可自由转到暗面。
- **土星环**：独立的环纹理（含卡西尼缝），按行星赤道面倾斜 26.7°，环的 UV 用极坐标映射径向纹理。
- **轨道与运动**：八条轨道线；行星公转速度按真实周期开方缩放（水星 28 秒一圈、海王星约 4 分钟），自转速度按真实自转周期缩放，金星、天王星自转方向为逆行。
- **太阳表面**：程序化着色器（多层 fbm 噪声缓慢流动 + 边缘暗化），不依赖贴图。
- **信息联动**：左上角标题卡随焦点显示该天体的真实数据（直径、距日 AU、公转周期）。
- **移动端适配**：≤860px 自动切为上下两行工具栏（星球名称可横向滑动 + 图标按钮），竖屏取景独立调参，支持触摸拖动与双指缩放。

## 比例说明

真实比例下太阳系的空旷程度无法同屏展示（海王星距日 30 AU，是太阳直径的 3000 多倍）。这里做了视觉压缩：

- 行星半径 ∝ (真实半径 / 地球半径)^0.35
- 轨道半径 ∝ 4.0 + 4.6 × (AU)^0.62
- 公转周期按 AU^0.5 缩放，自转周期按真实值开方缩放

数据本身（直径、距日、公转/自转周期）均为真实值。

## 运行

```
双击 index.html（推荐 Chrome / Edge）
```

不需要服务器、不需要联网，所有行星贴图都以 base64 内嵌。

## 文件

| 文件 | 说明 |
|---|---|
| `index.html` | 页面本体：界面、交互、渲染逻辑 |
| `three.min.js` | three.js r128（UMD） |
| `planet-assets.js` | 九张贴图：太阳系八大行星 + 土星环（base64） |

## 操作

- 拖动鼠标 / 单指拖动：旋转视角
- 滚轮 / 双指捏合：缩放
- 双击：回到全景
- 空格：暂停/继续自转
- `R` 重置、`F` 全屏、方向键微调

## 数据来源
